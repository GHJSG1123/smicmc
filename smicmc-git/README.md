## 一、管理后台

访问地址：`https://smicmc.qd.je/#/admin`（或者「我的」页面最下面点「管理后台」）

**默认口令：`gua2026`**

能做的事：

- 查看所有待处理举报，一键删除被举报的内容
- 查看最新 30 条帖子，可删除
- 举报可标为「忽略」

### 还需要配置一样东西（否则后台是空的）

后台要绕过数据库的权限限制才能看到举报、删帖，所以需要一个**服务端密钥**。

1. Supabase → 项目 → **Settings → API Keys** → **Secret keys** → 复制 `sb_secret_...`
2. Netlify → 你的站点 → **Site configuration → Environment variables** → **Add a variable**
   - Key：`SUPABASE_SERVICE_KEY`
   - Value：粘贴那个 `sb_secret_...`
3. 想在 Netlify 里改口令的话，再加一个：
   - Key：`ADMIN_PASSWORD`
   - Value：你想要的口令
4. 加完回 **Deploys** → 点 **Trigger deploy**（环境变量改了要重新部署才生效）

⚠️ **这个密钥绝对不能写进 `public/` 里的任何文件**。它只存在于 Netlify 的服务器环境里，浏览器拿不到。
